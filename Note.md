Access-Control-Allow-Credentials: true - this allows the browser to send a cookie inside browser cookie jar , this should be turn off if am using a jwt since am not using a browser cookie jar and am storing it to a localstorage
Access-Control-Allow-Origin - its basically the allowed origin my backend will allow an api to send a response e.g(config.setAllowedOrigins(List.of("https://my-example-website.com")); so if this origin are in the list of my allowed origin, the backend will allow an api to make a response
